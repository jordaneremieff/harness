Summarize the selected work for the operator in plain English.

Selected work and optional focus or comparison:
$ARGUMENTS

Treat questions and action phrases in the arguments as summary focus, not
permission to do the work. Without a work selection, summarize the latest
substantive task in this conversation and its related agent reports.
Exclude unrelated work.

Use visible evidence first. Use public read-only history or session tools
only to fill relevant gaps. Do not scan unrelated sessions or read private
stores. If evidence is unavailable, state the specific limit.

For an ordinary recap, explain:
- What the work was meant to achieve.
- What actually changed or what the agents learned.
- Why that result matters in ordinary use.
- What remains unfinished, uncertain, blocked, or subject to approval.

For an explicit comparison such as "since the last recap", identify and
briefly name the requested earlier reference for the same work. Report
material changes in outcomes, evidence, blockers, and decisions, and their
practical effect. Omit settled background. Retain unchanged constraints
that affect the current state or next act. Distinguish corrections to
earlier reports from actual changes in the work.

If that earlier reference is missing or ambiguous, state the exact limit
and summarize the known current state without inventing a comparison.
Reference recovery is not a required operator step merely because comparison
is unavailable. Missing later evidence does not prove an unchanged state;
state that gap.

Distinguish verified results from agent reports. Do not present a proposal,
an attempted action, or a local change as a completed release.

Group related work by outcome, not by agent. Avoid technical vocabulary.
Explain necessary terms. Include paths, commands, identifiers, and test
details only when they help the operator understand or act.

Aim for 150–250 words, with fewer for simple work. Preserve material limits.
End with a decision or next step only when source evidence establishes
that the work requires it. An unspecified detail alone establishes no
required decision. Do not invent an action or approval request.

Do not change files, start or resume agents, run tests, or continue the work.
Return the summary in chat. Create no report file or clipboard copy.
