# Handoff

## Purpose and arrangement <!-- required -->
What the receiving session continues and the current division of work, in one or two sentences.

## Operator directions <!-- required -->
Carried operator decisions verbatim in quotes, each with its source and scope.

## Standing rules <!-- required -->
The rules the receiver must keep: roster, boundaries, prohibitions.

## Verified state <!-- required -->
What is true now, each fact with the path, command output, or source checked.

## Owned agents <!-- required -->
The live agents this session owns, with the exact result references still awaited.

## Unread inputs <!-- required -->
Queued or expected inputs the receiver must handle.

## Next actions <!-- required -->
Ordered next steps, each with its completion condition.

## Thread ID
The threads the receiver must rejoin, update, or close. Keep the participation text of a create or join within 256 characters and a post message within 8,000 characters; write longer content to a file and post its path.
