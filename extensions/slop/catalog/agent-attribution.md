# Agent and model attribution

## Recognition

A commit message or a comment credits the agent or the model that wrote it, with a trailer such as `Co-authored-by: Claude` or a line such as `Generated with Copilot`. The text records who produced the change instead of what the change does.

## Cost

The attribution says nothing about the code, adds noise to every log, and ties the history to a tool that will change. In this repository it breaks the rule that history describes the implementation and not the session that made it.

## Repair

Delete the trailer or the line. If the reason for the change matters, state the reason in the commit body.

## Examples

Slop:

```commit
Add retry to the fetch client

Co-authored-by: Claude <noreply@example.com>
```

Better:

```commit
Add retry to the fetch client

The server drops about one request in fifty under load.
```

Slop:

```ts
// Generated by ChatGPT. Review before use.
export const limits = { retries: 3 };
```

Better:

```ts
export const limits = { retries: 3 };
```

## Detectors

```json
[{ "id": "attribution", "in": ["commit", "comment"],
   "pattern": "^\\s*(?:co-authored-by|generated-by|assisted-by)\\s*:.*\\b(?:claude|chatgpt|gpt|copilot|gemini|codex|cursor|ai|llm)\\b|\\b(?:generated|written|created|authored)\\s+(?:with|by)\\s+(?:an?\\s+)?(?:claude(?:\\s+code)?|chatgpt|gpt-?\\d[\\w.]*|copilot|gemini|codex|cursor|ai|llm)\\b" }]
```

## Notes

A commit that changes how the code talks to a model provider can name that provider. The detector looks only for attribution trailers and authorship lines.
